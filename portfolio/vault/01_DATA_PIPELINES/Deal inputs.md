# Deal inputs

ARV, rehab, contingency, assignment fee, earnest money, marketing spend, buyer cost rate, minimum buyer margin and close rate. Example values come from the v1 workbook's own example deal so the audit compares like with like.

Uncertainty for the [[Deal Monte Carlo]]: ARV σ 8%, rehab overrun 10% ± 15%. These are assumptions, not market estimates; comps should replace them. Used by [[Deal Analyzer v2]].
