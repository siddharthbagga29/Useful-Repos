# Research vault

Open this folder in [Obsidian](https://obsidian.md) (free) to browse it as a graph. The portfolio builds its
knowledge graph from these same files at build time, so a note added here appears on the site after the next deploy.

- `00_CORE_THESES/` — the claims I am testing
- `01_DATA_PIPELINES/` — where the data comes from and what it leaves out
- `02_MODELS_AND_SIMULATIONS/` — backtests, Monte Carlo and valuation models
- `03_PEER_REVIEW_LOGS/` — what I got wrong and how it was fixed
- `04_REFERENCES/` — papers and prior work

Link with `[[Note name]]`. Tag in the front matter. Every number in a note must come from a script or a model in the
repository, never typed from memory.
