# Deal Analyzer v2

MAO = ARV × 70% − rehab × (1 + contingency) − fee. Buyer all-in = contract + fee + rehab with contingency + buyer costs. Signal requires contract ≤ MAO, buyer margin ≥ minimum and positive expected profit (close-rate weighted). The workbook and the web model tie to the cent; the release checks enforce it.
