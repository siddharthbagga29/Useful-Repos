Put property photos in this folder, then paste the path into the
"Photo URL" field in admin.html — for example:

    assets/properties/hp-1001.jpg

Guidance
  • 4:3 landscape, at least 1200 x 900 px
  • JPEG, under ~300 KB each (compress before uploading)
  • Name files after the property reference so they are easy to find

If a property has no photo the site shows branded architectural
artwork instead, so listings never look broken.
